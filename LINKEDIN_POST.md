🚀 Project completed: LearnHub – an E-Learning Android app!

As part of my Android Development internship with @Sqrock IT Solutions, I built a full online-learning app where students can browse courses, enroll, watch video lessons and track their progress.

📱 Features
• Register / login / logout with Firebase Authentication
• Home screen with featured & popular courses, categories and search
• Course details with instructor, description, duration and one-tap enrollment
• Video lessons with "mark as completed" and live progress tracking
• Personal dashboard showing enrolled courses and completed lessons, plus profile editing

🛠 Tech stack
Kotlin · Android Studio · XML layouts + ViewBinding · Material Design 3 · RecyclerView · Firebase Auth · Cloud Firestore · Glide · Coroutines

🔥 Firebase integration
Firestore stores the course catalogue, user profiles and per-user enrollment progress, so progress is saved across devices.

💡 What I learned
Structuring an Android app around a single repository layer, handling async Firebase calls with coroutines, designing clean RecyclerView-based UIs, and modelling data in Firestore.
